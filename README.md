# 🌦️ Weather App - React

A simple and responsive weather application built with **React** and styled using **SCSS**. It fetches real-time weather data using a public **REST API**.

## ⚙️ Tech Stack

- **React** – JavaScript library for building user interfaces
- **SCSS** – modular, maintainable styles
- **REST API** – for fetching weather data (e.g., from OpenWeatherMap)
- **Fetch API** – to make asynchronous requests
- **CRA**

## ✨ Features

- Search weather by city name
- Display of current weather:
  - temperature
  - weather conditions
  - humidity
  - wind speed
- Error handling (e.g. city not found)
- Responsive layout
